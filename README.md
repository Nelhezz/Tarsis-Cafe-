# Кофейня «Тарсис»

**[Открыть сайт →](https://nelhezz.github.io/Tarsis-Cafe-/)**

Лендинг выдуманной первой кофейни на Марсе. Стоит на плато Тарсис, в 300 км от вулкана Олимп.

## Что внутри

- **3D-Марс** по настоящей карте NASA: рельеф кратеров и каньонов, тонкая пыльная атмосфера, граница дня и ночи. Планета следит за курсором и перелетает между разделами при прокрутке.
- **Фарфоровая чашка в 3D** с отражениями и мягкими тенями. При выборе напитка в меню бариста «наливает» новый: тигровая крема, розетта, сердце из пены, спираль из сливок.
- **Заголовок реагирует на курсор**: буквы становятся толще, когда мышь рядом.
- **Свой курсор и «магнитные» кнопки**, плавная прокрутка, горизонтальный раздел «Путь зерна», бегущая строка, которая ускоряется от прокрутки.
- **Настоящие факты о Марсе**: вода кипит при +2 °C, сила тяжести 0,38 g, сутки длятся 24 ч 39 мин.

## Как посмотреть

Проще всего открыть [сайт по ссылке](https://nelhezz.github.io/Tarsis-Cafe-/).

Чтобы запустить у себя и что-то поменять, сборка не нужна. Откройте `index.html` через любой локальный сервер, например:

```bash
python3 -m http.server
```

и перейдите на `http://localhost:8000`. Если открыть файл двойным щелчком, браузер может не загрузить карту Марса.

## Технологии

HTML, CSS и JavaScript. Библиотеки подключаются с CDN: [three.js](https://threejs.org) r128, [GSAP](https://gsap.com) 3.12 со ScrollTrigger, [Lenis](https://lenis.darkroom.engineering) 1.1. Шрифты Unbounded и Onest из Google Fonts.
